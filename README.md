# MRI-AI
ในแต่ละปีมีผู้ป่วยรายใหม่ที่ได้รับการวินิจฉัยว่าเป็นเนื้องอกในสมองหลายแสนคนทั่วโลกการระบุตำแหน่งและขอบเขตของเนื้องอก อย่างแม่นยำมีความสำคัญอย่างยิ่งต่อการวางแผนรักษาและการผ่าตัด แต่นี่คืองานที่ใช้เวลาและความเชี่ยวชาญสูงมากจากรังสีแพทย์  Notebook นี้คือการสร้าง "ดวงตาที่สอง" ให้กับแพทย์ โดยใช้เทคนิค Deep Learning ภายใต้สถาปัตยกรรม Attention U-Net
